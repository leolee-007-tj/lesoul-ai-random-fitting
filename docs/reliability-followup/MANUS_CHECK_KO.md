# Manus 동기화 후 읽기 전용 확인

기존 Manus 프로젝트에서 새 main을 가져오고 의존성을 lockfile 기준으로 설치한 뒤, 프로젝트 Terminal에서 `node scripts/check-manus-runtime.mjs`를 실행하세요. 원래 DB·저장소·계정 설정을 유지해야 합니다. 비밀값을 저장소·채팅에 붙이지 마세요.

이 도구는 필요한 설정의 존재와 기존 DB의 테이블·열을 SELECT로만 확인합니다. 실제 키·DB 주소·DB 원문 오류·서명 다운로드 주소는 출력하지 않습니다. `CONFIGURED_NOT_VERIFIED`는 연결 성공이 아닙니다. 이미지·AI 추론·저장소 업로드를 호출하지 않습니다.

`SCHEMA_OR_PERMISSION_MISMATCH`가 나오면 해당 항목의 기존 migration과 실제 테이블을 비교하고 백업 후 필요한 변경만 검토하세요. 이 스크립트는 migration이나 db:push, 초기화, 데이터 이동을 실행하지 않습니다. 코드 동기화만으로 DB 구조·기존 파일 접근·제공자 잔여량까지 검증됐다고 처리하지 않습니다.

기존 자료 1개 열기, 새 업로드, 관리자 로그인, 실제 AI 요청은 Manus의 기존 승인·사용 가능량 안에서 따로 확인해야 합니다. 이 개발에서 실제 Manus 자격정보나 운영 DB에 접근하지 않았으므로 해당 결과는 미검증입니다.

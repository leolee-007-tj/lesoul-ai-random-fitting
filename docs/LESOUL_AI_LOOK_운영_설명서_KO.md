# LESOUL AI LOOK 운영 설명서

**버전 기준:** 최종 운영 배포본  
**서비스 주소:** [https://lesoulai-xabhv8qd.manus.space](https://lesoulai-xabhv8qd.manus.space)  
**대상:** 소유자, 관리자, VIP 운영 담당자 및 일반 고객 안내 담당자

## 1. 서비스 개요

LESOUL AI LOOK은 여성 고객을 위한 프리미엄 스타일링 및 상품 탐색 웹앱입니다. 고객은 등록된 실제 상품을 둘러보고, 스타일 매치 추천을 확인하고, 구매 목록을 정리할 수 있습니다. 관리자는 상품, 카테고리·실측 항목, 코디 추천, 계정, 공개 소개 문구, QR 안내를 관리합니다.

> **운영 원칙:** 모든 가격은 CNY 기준입니다. 상품명·설명·코디 문구는 한국어, 중국어, 영어 중 편한 언어로 입력할 수 있으며 고객 화면에서는 현재 시스템 언어에 맞는 저장 번역문이 표시됩니다.

| 구분 | 주요 권한 | 데이터 기준 |
|---|---|---|
| NORMAL | 상품 탐색, Style Match, 구매 목록, 프로필 | 브라우저별 익명 visitorId |
| VIP | NORMAL 기능 및 VIP 스타일 기능 | 고유 계정 userId |
| ADMIN | Operations, 상품·핏·코디·계정·출시 설정 관리 | 고유 관리자 계정 userId |
| OWNER | ADMIN 관리 범위 및 핵심 운영 설정 | 소유자 계정 userId |

## 2. 고객 이용 흐름

고객은 로그인 후 홈 화면에서 상품 둘러보기, 매치, 구매 목록, 프로필로 이동합니다. NORMAL 공용 로그인은 접근 권한만 제공하며, 저장한 룩·구매 목록·사용량은 각 브라우저의 visitorId로 분리됩니다. 따라서 다른 고객이 동일한 공용 로그인 정보를 사용해도 서로의 저장 데이터가 섞이지 않습니다.

| 고객 화면 | 고객이 할 수 있는 일 | 운영 시 확인할 사항 |
|---|---|---|
| Home | 서비스 진입, 주요 기능 이동 | 시스템 언어에 맞는 문구 표시 |
| Browse Products | 실제 등록 상품 탐색 및 상세 확인 | 상품명·설명·가격·이미지·재고 상태 |
| Match | 특정 상품 기준 코디 또는 스타일 추천 | 비공개·품절 정책 및 큐레이션 코디 |
| Purchase List | 관심 상품을 모아 구매 안내 확인 | QR·구매 안내문 최신 상태 |
| Profile | 저장 룩, 관심 상품, 최근 구매 요청 확인 | 사용자 데이터는 계정/visitorId별 분리 |

## 3. 관리자 로그인과 계정 관리

관리자는 일반 고객용 공용 로그인과 별도로, 반드시 고유한 ID와 비밀번호를 사용합니다. 비밀번호는 다른 관리자와 공유하지 말고, 최소 8자 이상이며 예측하기 어려운 조합으로 설정하십시오. 공용 테스트 로그인 정보나 관리자 비밀번호를 공개 소개 페이지, SNS 게시물, 고객 안내문에 넣지 않는 것이 안전합니다.

관리자 계정은 **Operations → User Management → Admin Account Management**에서 생성·관리합니다. 새 관리자 계정은 첫 관리자 콘솔 접속 시점부터 개별적으로 48시간 체험이 시작됩니다. 한 관리자 계정의 만료는 다른 관리자 계정에 영향을 주지 않습니다.

| 계정 상태 | 의미 | 운영 조치 |
|---|---|---|
| 체험 시작 전 | 아직 관리자 콘솔에 접속하지 않음 | 필요 시 ID·비밀번호만 전달 |
| 체험 진행 중 | 첫 접속 후 48시간 이내 | Release Control에서 QR·안내 설정 확인 |
| 체험 만료 | 관리자 API와 운영 화면 접근이 차단됨 | 만료 팝업의 결제 QR 및 사용 방법 QR 안내 |

## 4. 상품 등록 및 이미지 업로드

상품은 **Products → Add product**에서 등록합니다. 먼저 표시 카테고리를 선택하고, 상품명과 CNY 가격을 입력합니다. 시즌, 색상, 스타일, 설명, 브랜드, 판매 상태, 신상품 여부는 필요에 따라 추가합니다. 상품명과 설명을 저장하면 EN/KO/ZH 번역 필드가 함께 관리되어 고객 언어에 맞춰 표시됩니다.

상품 이미지는 앞면, 뒷면, 디테일 1, 디테일 2의 최대 네 슬롯을 사용합니다. 일괄 업로드 트레이를 이용하면 여러 파일을 선택한 뒤 각 슬롯에 배정할 수 있습니다. 현재 배포본은 **순백 배경 AI 생성·재생성·검토 기능을 완전히 제거**했으므로, 해당 기능으로 이미지 생성 비용이 발생하지 않습니다.

> **자동 압축 기능:** 큰 카메라 사진은 업로드 전에 브라우저에서 자동 최적화됩니다. 2048px를 넘는 이미지는 비율을 유지해 축소되고, 큰 파일은 WebP 또는 JPEG로 압축됩니다. 이미 작고 가벼운 사진이나 압축 결과가 더 큰 사진은 원본을 유지합니다.

| 이미지 항목 | 권장 내용 | 업로드 시 동작 |
|---|---|---|
| 앞면 | 제품 전체 실루엣이 보이는 정면 사진 | 자동 압축 후 저장 |
| 뒷면 | 제품 전체 후면 사진 | 자동 압축 후 저장 |
| 디테일 1 | 소재, 여밈, 로고, 패턴 등 핵심 정보 | 자동 압축 후 저장 |
| 디테일 2 | 추가 디테일 또는 부분 확대 | 자동 압축 후 저장 |

업로드 영역에는 `이미지 용량을 최적화하는 중…` 또는 `이미지 최적화: 원본 → 결과`가 표시됩니다. 최적화 중에는 중복 업로드를 막기 위해 슬롯 버튼과 일괄 배정이 잠시 비활성화됩니다.

## 5. 카테고리·실측·코디 관리

**Categories & Fit Fields**에서 상품 종류를 만들고, 해당 종류에 필요한 실측 항목을 선택합니다. 선택한 항목은 드래그 앤 드롭 또는 위·아래 이동으로 표시 순서를 정할 수 있습니다. 상품 등록 화면에는 중복된 실측 입력이 없으며, 실제 실측 관리는 Fit Data 영역에서 수행합니다.

큐레이션 코디는 실제 등록 상품만 이용해 구성합니다. 상의·하의·아우터·드레스·신발·가방 등 카테고리 기준으로 상품을 고른 뒤, 코디 이름과 추천 이유를 입력합니다. 고객의 Style Match는 저장된 큐레이션 코디를 우선 활용하며, 한 번에 최대 3개의 완성 코디를 제안합니다.

| 운영 작업 | 권장 순서 |
|---|---|
| 새 카테고리 | 카테고리 생성 → 실측 항목 선택 → 순서 정리 → 저장 |
| 새 상품 | 카테고리 → 이름·가격 → 이미지 1~4장 → 판매 상태 → 저장 |
| 새 코디 | 실제 상품 선택 → 중복 확인 → 이름·추천 이유 입력 → 저장 |
| 상품 수정 | 상품 카드의 수정 버튼 → 이미지/가격/상태 변경 → 저장 |

## 6. Release Control과 공개 소개 페이지

**Release Control**은 운영 정책을 조정하는 소유자용 화면입니다. 여기에서 가게 이름, 공개 소개 문구(EN/KO/ZH), 공개 범위, 생성 정책, 구매 목록 정책, 구매 QR 및 관리자 체험 QR을 관리합니다. 가게 이름과 공개 소개 문구는 고객 헤더 및 `/about` 공개 소개 페이지에 반영됩니다.

공개 소개 페이지는 로그인 전 방문자에게 서비스 가치와 이용 흐름을 안내합니다. 공유 링크 복사 버튼으로 소개 페이지 주소를 WeChat, SNS, 블로그 등에 게시할 수 있습니다. 실제 고객 후기나 평점은 운영자가 임의로 작성하거나 표시하지 마십시오.

| 설정 | 적용 위치 | 운영 목적 |
|---|---|---|
| 가게 이름 | 고객 헤더, 공개 소개 페이지 | 브랜드 일관성 |
| EN/KO/ZH 소개 문구 | `/about` | 언어별 첫 방문자 안내 |
| 구매 안내문·QR | 구매 목록 및 상품 구매 안내 | 수동 결제 안내 |
| 체험 만료 결제 QR | 만료된 관리자 팝업 | 수동 연장 안내 |
| 체험 사용 방법 QR | 만료된 관리자 팝업 | 운영 방법 안내 |

## 7. 관리자 2일 체험과 QR 안내

관리자 체험은 계정별로 계산됩니다. 새 관리자 계정이 관리자 콘솔에 처음 접속한 시간을 기준으로 48시간 동안 유효합니다. 만료 후에는 일반 고객 기능이 아니라 **관리자 운영 권한만** 제한됩니다. 고객·VIP의 현재 접근 흐름은 변경되지 않습니다.

만료 안내 팝업에는 두 종류의 QR을 분리해 표시할 수 있습니다. 첫째는 수동 연장 또는 결제 안내 QR이며, 둘째는 관리자 사용 방법 QR입니다. 두 QR은 Release Control에서 이미지 파일로 업로드·삭제할 수 있습니다. 실제 결제는 앱에서 자동 처리되지 않으므로, 수동 확인 절차는 별도로 운영해야 합니다.

> **중요:** QR 이미지와 안내문을 실제 운영 시작 전에 반드시 등록하십시오. 만료 이후에는 해당 관리자 계정의 운영 설정 접근이 제한될 수 있습니다.

## 8. 운영 점검표

매주 한 번 아래 항목을 확인하면 일반적인 운영 오류를 줄일 수 있습니다.

| 점검 항목 | 확인 내용 |
|---|---|
| 상품 상태 | 판매 중·예약 주문·품절·비공개 상태가 실제 재고와 일치하는지 |
| 가격 | CNY 정상가·할인가·할인율이 올바른지 |
| 이미지 | 앞면·뒷면·디테일이 상품과 일치하고 너무 흐리지 않은지 |
| 번역 | 상품명·설명·코디 문구가 EN/KO/ZH에서 자연스럽게 보이는지 |
| QR | 고객 구매 안내 QR, 관리자 결제 QR, 사용 방법 QR이 최신인지 |
| 계정 | 관리자별 체험 상태와 비밀번호 관리 상태가 적절한지 |
| 공개 소개 | 가게 이름, 소개 문구, 공유 링크가 현재 브랜드 정책과 맞는지 |

## 9. 자주 묻는 문제

| 상황 | 확인 및 조치 |
|---|---|
| 상품 이미지가 크게 업로드됨 | 자동 압축 안내가 표시되는지 확인하고, 매우 큰 원본은 Wi‑Fi 환경에서 다시 시도 |
| 이미지 업로드가 실패함 | 이미지 형식과 8MB 제한을 확인하고, 파일을 다시 선택 |
| 상품명이 다른 언어로 보이지 않음 | 저장 시 자동 번역이 완료되었는지 확인 후 상품을 다시 저장 |
| 관리자 화면에 접근하지 못함 | 계정별 48시간 체험 상태와 만료 QR 안내를 확인 |
| 구매 QR이 오래됨 | Release Control 또는 상품 구매 설정에서 새 QR로 교체 |
| 순백 배경 생성 메뉴가 없음 | 정상입니다. 비용 절감을 위해 해당 AI 기능은 최종본에서 제거되었습니다. |

## 10. 최종 운영 권고

현재 배포본은 최종 운영 기준으로 사용할 수 있습니다. 다만 실제 공개 전에는 소유자 기기에서 관리자 로그인, 상품 1개 등록, 이미지 1~4장 업로드, 상품 상세 확인, 구매 QR 안내, 공개 소개 링크를 한 번씩 점검하십시오. 이 점검만으로 권한·콘텐츠·QR 이미지의 초기 설정 오류를 대부분 예방할 수 있습니다.

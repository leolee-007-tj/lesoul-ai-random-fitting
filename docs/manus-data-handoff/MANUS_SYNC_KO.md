# 기존 Manus 데이터와 LESOUL 코드 연결

현재 AI OS 수정·전달 기준은 `leolee-007-tj/lesoul-ai-fitting`의 main이다. 전달된 Manus 지도는 이전 저장소 `lesoul-ai-random-fitting`과 Manus 폴더 `/home/ubuntu/lesoul-ai-random-fitting`을 가리킨다. **Manus 작업 폴더 이름을 바꿀 필요는 없다.** 기존 WebDev 프로젝트 XABHv8QdBoCpfYVqBJuXsY, DB 환경변수와 Forge 저장소 연결은 유지하고 새 저장소의 검증된 코드만 가져온다.

전달 문서의 커밋 171cba1은 로컬 검증 기준으로 사용하지 않았다. 조회한 이전 원격 main은 fec0344였고 새 원격은 e307182였다. 두 저장소는 분기되어 있으므로 이전 main으로 강제 초기화하거나 전체 덮어쓰지 않는다. 이전 저장소의 CI/자동 배포 훅을 이번 변경에 가져오거나 활성화하지 않았다.

## 기존 데이터를 유지하는 구조

- DB: `DATABASE_URL`이 연결하는 MySQL/TiDB. 상품·Care Label·고객 생성 결과의 참조는 이 DB에 있다.
- 이미지: Forge/S3 객체 저장소. DB에는 `/manus-storage/{key}` 또는 storage key를 보존한다. 이 경로는 Mac·Manus 작업 폴더 경로가 아니다.
- 새 사진 업로드는 기존처럼 새 키를 만들며, 기존 상품·사진의 키나 고정 상품 ID는 변경하지 않는다.
- 임시 서명 URL을 영구 DB 값으로 바꾸지 않는다. 브라우저가 기존 프록시 경로를 요청하면 서버가 새로운 서명 주소를 받아 307 응답한다.
- 코드 import만으로 DB, 사진, migration이 옮겨지거나 적용되지는 않는다. 코드에 포함되지 않은 기존 환경 설정을 그대로 유지해야 한다.

## 이번 수정

사진 프록시는 성공과 실패 모두 no-store로 응답한다. 일시적 저장소 오류 후 회복된 기존 사진이 이전 오류 캐시 때문에 계속 가려지는 것을 방지한다. Forge 오류 원문·서명 URL·HTTP 예외의 상세값을 사용자 오류와 서버 로그에 내보내지 않는다. 서명 URL은 유효한 HTTPS 형식인지 확인하고, 로그인 정보가 포함되거나 잘못된 응답은 거부한다. 기존 정상이미지 경로·키 규칙·업로드 API는 유지한다.

`pnpm check:manus`는 기존 상품 이미지, Care Label, 생성 결과, 디스플레이 이미지의 **열 존재만 LIMIT 0으로 검사**한다. 행이나 실제 사진·고객정보를 출력하지 않는다. DB 종료 오류도 비밀 원문 대신 고정 분류로 출력한다. 이 명령은 migration·업로드·AI·자동 배포를 실행하지 않는다.

## Manus에서 동기화 후 확인

1. 기존 DB와 객체 저장소의 공급자 백업 상태를 먼저 확인한다. 이 로컬 작업에서 운영 백업을 만들었다고 가정하지 않는다.
2. Manus 작업 내용·Git 상태를 보존하고 새 저장소의 main을 가져온다. 분기/수정사항이 있으면 검토하여 병합하며 reset --hard/강제 덮어쓰기를 하지 않는다. 기존 환경변수는 재작성하거나 Git에 올리지 않는다.
3. lockfile 기준 의존성 설치 후 `pnpm check`, `pnpm test`, `pnpm build`를 실행한다.
4. 기존 환경에서 `pnpm check:manus`를 실행한다. 설정 존재 표시는 연결 검증과 다르다. MISMATCH는 기존 스키마와 migration을 비교할 대상이며 `db:push`를 무조건 실행하지 않는다.
5. 기존 상품·Care Label ID와 사진이 열리는지, 새 업로드가 기존 자료를 건드리지 않는지 미리보기에서 확인한다. 이 로컬 검증은 실제 Manus DB·사진 접근 성공을 대신하지 않는다.
6. GitHub push와 실제 사이트 반영은 별개다. 연결된 Manus 저장소 주소와 가져온 커밋을 확인하고 기존 게시 절차를 따른다. 자동 동기화·배포 훅 활성화는 확인하지 않았다.

원본 지도에 있는 행 수(products 187, careLabelProducts 391 등)는 제공자가 조회한 시점의 정보이며 현재 로컬에서 재조회한 값이 아니다. DB·스토리지 연결 주소/키를 채팅이나 GitHub에 붙여 넣지 않는다.

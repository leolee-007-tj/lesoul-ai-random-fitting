# 기존 중국어 상품의 번역 누락·오인식 수정

## 원인과 확인 범위

고객 화면은 선택 언어의 저장값이 없으면 원문으로 되돌아간다. 예전 편집기는 비어 있는 한국어/영어/중국어 입력칸에 원문을 복사해 저장할 수 있었다. 기존 번역 판정은 일부 중국어 이름·설명만 처리하고 색상·계절·스타일의 복사값과 빈 선택항목을 일관되게 구분하지 못했다. 기존 번역 보완은 정상 번역도 덮어쓰고, 실패 건수는 화면에 명확히 표시하지 않았으며 관리자 목록만 갱신했다. 실제 Manus 상품 행은 이번 작업에서 읽지 않았으므로 개별 상품의 저장값까지 확인했다고 주장하지 않는다.

## 변경

- 편집기의 빈 번역칸은 빈 상태로 유지한다. 원문은 별도 원문 필드에 보존한다.
- 공통 판정으로 누락·중국어/한국어 원문이 다른 언어 칸에 그대로 복사된 값을 검사한다. 이름·설명·계절·색상·스타일에 같은 규칙을 적용한다. 의도적으로 빈 선택항목은 반복 작업으로 잡지 않는다. 문자/동일값 검사는 번역 품질 전체의 언어학적 검증이 아니다.
- 번역 보완은 문제 필드만 갱신하고 정상적인 기존 수동 번역·원문·상품 ID·사진 키는 보존한다. 제공자가 원문을 다시 반환하면 실패 처리하고 그 상품을 갱신하지 않는다.
- 관리자 화면은 번역 확인 필요 수와 완료·실패·남은 수를 표시한다. 실패·미완료를 성공으로 합산하지 않고 오류를 안내한다. 고객 카탈로그의 캐시도 무효화해 다음 조회에서 갱신한다.
- 상품 저장의 성공과 번역 완료를 별도 반환·표시한다. 번역 실패가 있어도 승인된 기존 원문 저장 기능은 보존하되 미완료를 알린다.
- 새 편집기는 상품명·설명과 함께 메타데이터 전체를 번역한다. 완전한 번역을 이미 제공한 저장은 서버가 다시 번역하지 않아 중복 호출을 방지한다. 원문만 바꾼 경우는 갱신 필요를 재판정한다.

## 실제 검증과 미실행

helper 테스트와 실제 tRPC owner route 호출을 이용한다. DB·AI는 fixture이며 운영 키·상품 DB·실제 모델을 호출하지 않는다. 복사값 수리, 정상 번역 보존, 실패 시 무갱신·미완료 표시, 빈 선택항목의 반복 제외, 완전한 저장의 중복 번역 방지를 검증했다. 전체 검사·타입·빌드 결과는 VERIFICATION.json에 기록한다.

이번 변경은 코드 수정이다. 기존 Manus 상품의 실제 번역 데이터 보완은 실행하지 않았다. 동기화 후 관리자 ‘기존 상품 번역 보완’은 실제 Manus 번역 제공자와 기존 권한·잔여량을 사용하는 별도 작업이다. 이 작업을 실행하지 않은 상태에서 예전 상품 전체가 한국어로 바뀌었다고 주장하지 않는다. 사진 재업로드나 DB 초기화·새 migration은 필요하지 않다.

AI OS의 일반 원칙대로 보고된 한 증상에서 저장→판정→보완→표시→캐시 갱신까지 연결된 문제를 조사했다. 실제 유료 호출·운영 DB 변경·사이트 배포는 수행하지 않았다.

추가 회귀: 원문 변경 후 번역 제공자가 실패하면 기존 번역값이 남아 있어도 미완료로 반환한다. 제공자의 JSON은 고정된 15개 번역 필드·문자열·DB 길이 범위만 사용하며 예상 밖의 name 등 원문 필드는 적용하지 않는다. 실제 owner route fixture로 검증했다.

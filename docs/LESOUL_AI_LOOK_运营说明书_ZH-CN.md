# LESOUL AI LOOK 运营说明书

**版本基准：** 最终运营部署版  
**服务地址：** [https://lesoulai-xabhv8qd.manus.space](https://lesoulai-xabhv8qd.manus.space)  
**适用对象：** 所有者、管理员、VIP 运营人员及客户引导人员

## 1. 服务概述

LESOUL AI LOOK 是面向女性客户的高端风格搭配与商品浏览网页应用。客户可以浏览已登记的真实商品、查看 Style Match 搭配建议，并整理购买清单。管理员可以管理商品、分类与实测字段、搭配组合、账号、公开介绍文案和二维码说明。

> **运营原则：** 所有价格均以 CNY 显示。商品名、说明和搭配文案可以使用中文、韩文或英文输入；客户页面会根据当前系统语言显示已保存的对应翻译内容。

| 角色 | 主要权限 | 数据归属方式 |
|---|---|---|
| NORMAL | 浏览商品、Style Match、购买清单、个人资料 | 浏览器专属匿名 visitorId |
| VIP | NORMAL 功能及 VIP 风格功能 | 专属账号 userId |
| ADMIN | Operations、商品/尺码/搭配/账号/发布设置管理 | 专属管理员账号 userId |
| OWNER | ADMIN 管理范围及核心运营设置 | 所有者账号 userId |

## 2. 客户使用流程

客户登录后，可从首页进入商品浏览、搭配、购买清单和个人资料页面。NORMAL 共用登录只用于访问授权；已保存 LOOK、购买清单和使用次数按各浏览器的 visitorId 分开保存。因此，即使客户使用同一组共用登录信息，彼此的保存数据也不会混合。

| 客户页面 | 客户可执行的操作 | 运营时需确认的内容 |
|---|---|---|
| Home | 进入服务及主要功能 | 文案是否按系统语言显示 |
| Browse Products | 浏览真实登记商品和商品详情 | 商品名、说明、价格、图片、库存状态 |
| Match | 以指定商品为基础查看搭配或风格建议 | 下架/售罄政策和精选搭配 |
| Purchase List | 汇总感兴趣的商品并查看购买说明 | 二维码和购买说明是否最新 |
| Profile | 查看保存 LOOK、兴趣商品和最近购买请求 | 数据是否按账号/visitorId 分开 |

## 3. 管理员登录与账号管理

管理员必须使用与普通客户共用登录不同的专属 ID 和密码。请不要与其他管理员共用密码，并使用至少 8 位、难以猜测的密码组合。不要在公开介绍页、SNS 帖子或客户说明中公开测试登录信息或管理员密码。

管理员账号可在 **Operations → User Management → Admin Account Management** 中创建和管理。每个新管理员账号在首次进入管理员控制台时开始独立的 48 小时体验期；某个账号到期不会影响其他管理员账号。

| 账号状态 | 含义 | 运营操作 |
|---|---|---|
| 尚未开始体验 | 尚未进入管理员控制台 | 只需按需提供 ID 和密码 |
| 体验进行中 | 首次进入后 48 小时内 | 在 Release Control 确认二维码和说明 |
| 体验已到期 | 管理员 API 与运营页面被限制 | 按到期弹窗中的付款二维码和使用说明二维码操作 |

## 4. 商品登记与图片上传

请在 **Products → Add product** 中登记商品。先选择展示分类，再输入商品名称和 CNY 价格。可按需要补充季节、颜色、风格、说明、品牌、销售状态和新品标记。保存商品名称和说明时，EN/KO/ZH 翻译字段会一并保存，以便客户按当前语言查看。

商品图片最多使用四个槽位：正面、背面、细节 1、细节 2。也可以通过批量上传托盘先选择多个文件，再分别分配到各槽位。当前最终版本已**完全移除纯白背景 AI 生成、重新生成和审核功能**，因此不会因该功能产生图片生成费用。

> **自动压缩：** 较大的相机图片会在上传前由浏览器自动优化。超过 2048px 的图片会保持比例缩小；较大的文件会转换为 WebP 或 JPEG。已经较小的图片，或压缩后反而更大的图片，将保留原文件。

| 图片项目 | 建议内容 | 上传行为 |
|---|---|---|
| 正面 | 可清楚看到整体轮廓的正面图 | 自动压缩后保存 |
| 背面 | 可清楚看到整体后侧的图片 | 自动压缩后保存 |
| 细节 1 | 面料、扣件、标识、图案等重点信息 | 自动压缩后保存 |
| 细节 2 | 其他重点细节或局部放大图 | 自动压缩后保存 |

上传区域会显示“正在优化图片大小…”或“图片已优化：原始大小 → 优化后大小”。优化过程中，图片槽位按钮和批量分配会暂时禁用，以避免重复上传。

## 5. 分类、实测字段与搭配管理

在 **Categories & Fit Fields** 中创建商品类型，并选择该类型需要的实测字段。可通过拖放或上下移动调整字段显示顺序。商品登记页面不会重复显示实测输入；实际实测管理在 Fit Data 中完成。

精选搭配必须由已登记的真实商品组成。按上装、下装、外套、连衣裙、鞋履、包袋等分类选择商品后，填写搭配名称和推荐理由。客户的 Style Match 会优先使用已保存的精选搭配，每次最多提供 3 套完整搭配。

| 运营任务 | 建议顺序 |
|---|---|
| 新建分类 | 创建分类 → 选择实测字段 → 调整顺序 → 保存 |
| 新建商品 | 选择分类 → 填写名称和价格 → 上传 1~4 张图片 → 设置销售状态 → 保存 |
| 新建搭配 | 选择真实商品 → 检查重复 → 填写名称与推荐理由 → 保存 |
| 修改商品 | 点击商品卡编辑 → 修改图片/价格/状态 → 保存 |

## 6. Release Control 与公开介绍页面

**Release Control** 是所有者用于调整运营政策的页面。可在此管理店铺名称、公开介绍文案（EN/KO/ZH）、公开范围、生成政策、购买清单政策、购买二维码和管理员体验二维码。店铺名称与公开介绍文案会反映在客户页头和 `/about` 公开介绍页面。

公开介绍页面面向登录前访问者说明服务价值和使用方式。可使用“复制介绍链接”将页面地址发布到 WeChat、SNS 或博客。请勿自行编写或展示虚假的客户评价、评分或推荐内容。

| 设置项目 | 显示位置 | 运营目的 |
|---|---|---|
| 店铺名称 | 客户页头、公开介绍页 | 统一品牌表达 |
| EN/KO/ZH 介绍文案 | `/about` | 按语言引导首次访问者 |
| 购买说明与二维码 | 购买清单和商品购买说明 | 手动购买引导 |
| 体验到期付款二维码 | 已到期管理员弹窗 | 手动续期说明 |
| 体验使用说明二维码 | 已到期管理员弹窗 | 管理方法说明 |

## 7. 管理员两天体验与二维码说明

管理员体验期按账号独立计算。新管理员账号首次进入管理员控制台的时间起算，48 小时内有效。到期后受限制的是**管理员运营权限**，不会改变普通客户或 VIP 的既有访问流程。

到期提示弹窗可分别显示两类二维码：一类是手动续期/付款说明二维码，另一类是管理员使用方法二维码。两种二维码均可在 Release Control 上传或删除。应用不会自动完成付款，因此手动确认流程需要由运营方另行管理。

> **重要：** 请在实际运营开始前登记正确的二维码图片和说明文字。账号到期后，该管理员可能无法再进入运营设置页面更新二维码。

## 8. 运营检查清单

建议每周检查一次以下项目，以减少常见运营错误。

| 检查项目 | 确认内容 |
|---|---|
| 商品状态 | 在售、预售、售罄、未上架是否与真实库存一致 |
| 价格 | CNY 原价、折后价、折扣率是否正确 |
| 图片 | 正面、背面、细节是否属于对应商品且清晰可辨 |
| 翻译 | 商品名、说明、搭配文案在 EN/KO/ZH 下是否自然 |
| 二维码 | 客户购买二维码、管理员付款二维码、使用说明二维码是否最新 |
| 账号 | 各管理员体验状态和密码管理是否合适 |
| 公开介绍 | 店铺名称、介绍文案、分享链接是否符合当前品牌政策 |

## 9. 常见问题

| 情况 | 检查与处理 |
|---|---|
| 商品图片文件很大 | 确认已显示自动压缩提示；极大的原图建议在 Wi‑Fi 环境重试 |
| 图片上传失败 | 确认图片格式与 8MB 限制后重新选择文件 |
| 商品名未显示为其他语言 | 确认保存时自动翻译是否完成，再次保存商品 |
| 无法进入管理员页面 | 确认该账号的 48 小时体验状态及到期二维码提示 |
| 购买二维码过期 | 在 Release Control 或商品购买设置中更换新二维码 |
| 找不到纯白背景生成菜单 | 属于正常情况。为节省成本，该 AI 功能已从最终版本移除。 |

## 10. 最终运营建议

当前部署版可以作为正式运营版本使用。正式公开前，建议使用所有者设备完成一次管理员登录、登记 1 件商品、上传 1~4 张图片、查看商品详情、确认购买二维码说明并测试公开介绍链接。通过这一次检查，可以预防大多数初始权限、内容和二维码配置错误。
